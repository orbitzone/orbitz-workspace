# Orbitz Workspace — ícone vetorial

Redesenhado em SVG em 2026-11-03 a partir do relógio com órbita azul fornecido pelo usuário.
Fundo transparente, contornos simplificados, gradientes vetoriais e margens reduzidas
para melhorar a leitura no dock.

Fonte: `data/icons/hicolor/scalable/apps/io.orbitz.Workspace.svg`.
PNGs derivados via librsvg/Cairo nos tamanhos 16, 24, 32, 48, 64, 128, 256 e 512.
`data/io.orbitz.Workspace.png` é a versão 512 para a janela GTK.
